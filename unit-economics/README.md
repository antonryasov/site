# Калькулятор юнит-экономики

Отдельная страница-инструмент: LTV, CAC, окупаемость привлечения, предельный CAC и четыре рычага роста. Всё в одном файле `index.html` — стили, шрифты, логика. Без внешних зависимостей.

## Что внутри

| Блок | Что делает |
|---|---|
| Живая карточка в шапке | LTV, CAC, окупаемость и вердикт — обновляются при каждом изменении ввода |
| Калькулятор | Пять ползунков: чек, переменные расходы, CAC, покупки в год, срок жизни клиента |
| Результат | LTV/CAC, маржинальная прибыль, окупаемость, прибыль с клиента, предельный CAC, маржа в месяц |
| График | Накопленный денежный поток по месяцам: видно, где кривая пересекает ноль |
| Рычаги | Что даст +10% к чеку, −5 п.п. расходов, −20% CAC и +1 покупка в год. Нажатие применяет изменение |
| Пресеты | Отель с прямыми бронями, отель через OTA, кофейня, B2B-услуги, интернет-магазин |
| Нормы | Таблица ориентиров: здорово / на грани / опасно |

Ссылка с состоянием сохраняется в адресе (`#aov=14000&var=35&cac=5200&f=1.3&l=3`) — её можно отправить клиенту.

## Формулы

- Маржинальная прибыль = чек × (1 − переменные расходы, %)
- LTV = маржинальная прибыль × покупок в год × срок жизни
- LTV/CAC — норма от 3
- Окупаемость, мес. = CAC ÷ (маржа в год ÷ 12)
- Предельный CAC = LTV ÷ 3

## Публикация

1. Создайте репозиторий (например, `unit-economics`).
2. Загрузите в корень `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ссылка на основной сайт настраивается в начале файла:

```html
<script>window.SITE_URL = '../';</script>
```

Для отдельного репозитория: `window.SITE_URL = 'https://username.github.io/site/';`

## Правки

Исходники — в `src/` (`template.html`, `extra.css`, `app.js`). Общая типографика и шапка — в `../assets/tools/base.css`. Пересборка:

```bash
python3 build.py
```
