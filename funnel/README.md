# Диагностика воронки: где вы теряете деньги

Отдельная страница-инструмент: конверсии по этапам, стоимость лида и клиента, ROMI, узкое место и деньги, которые вернёт его починка. Один файл `index.html`, без зависимостей.

## Что внутри

| Блок | Что делает |
|---|---|
| Живая диагностика | Узкое место, потенциал в рублях в месяц и ROMI — сразу под заголовком |
| Воронка | Четыре этапа: визиты → обращения → квалификация → сделки, с конверсиями и сравнением с нормой |
| Результат | Выручка, валовая прибыль, прибыль после бюджета, CPL, CAC, сквозная конверсия |
| Симулятор улучшений | Три ползунка (по одному на конверсию): что будет со сделками, выручкой и прибылью |
| Приоритет | Список шагов, отсортированный по деньгам: что чинить первым |
| Пресеты | Отель, интернет-магазин, B2B-услуги, локальный бизнес |
| Нормы | Таблица ориентиров по конверсиям и ROMI |

Ссылка с состоянием сохраняется в адресе (`#v=24000&l=480&q=260&d=78&aov=38000&m=55&bud=420000`).

## Как считается

- Конверсии: обращения ÷ визиты, квалификация ÷ обращения, сделки ÷ квалификация
- CPL = бюджет ÷ обращения, CAC = бюджет ÷ сделки
- ROMI = (валовая прибыль − бюджет) ÷ бюджет
- Нормы для сравнения: 3% / 55% / 30%
- Потенциал шага = прирост прибыли, если довести его конверсию до нормы

## Публикация

1. Создайте репозиторий (например, `funnel`).
2. Загрузите в корень `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ссылка на основной сайт:

```html
<script>window.SITE_URL = '../';</script>
```

Для отдельного репозитория: `window.SITE_URL = 'https://username.github.io/site/';`

## Правки

Исходники — в `src/` (`template.html`, `extra.css`, `app.js`), общая основа — `../assets/tools/base.css`. Пересборка: `python3 build.py`.
