# Симулятор цены

Отдельная страница-инструмент: эластичность спроса, потеря клиентов при подъёме цены, кривая прибыли и точка максимума. Всё в одном файле `index.html` — стили, шрифты, логика. Без внешних зависимостей.

## Что внутри

| Блок | Что делает |
|---|---|
| Живая карточка в шапке | Оптимальная цена, прибыль сейчас и при оптимуме, потеря клиентов при +10% |
| Ввод | Цена, переменные затраты на единицу, продажи в месяц, эластичность — ползунки и поля |
| Результат | Цена, объём, выручка, прибыль, изменение прибыли и маржа по выбранному изменению цены (−30…+50%) |
| График | Кривая прибыли по цене, метки «ваша цена», «выбранная цена» и «максимум» |
| Сравнение | Семь цен от −20% до +30%: сколько клиентов, какая выручка и какая прибыль |
| Пресеты | Отель (ночь), кофейня (напиток), ресторан (сет), B2B (подписка) |

Состояние сохраняется в адресе (`#p=14000&v=4900&q=250&e=1.45&d=10`) — ссылку можно отправить клиенту.

## Формулы

- Спрос: `Q(p) = Q₀ · (p / p₀)^(−E)`
- Прибыль: `П(p) = (p − VC) · Q(p)`
- Цена максимума прибыли: `p* = VC · E / (E − 1)` — работает при эластичности больше 1
- Потеря клиентов при подъёме цены на k%: `1 − (1 + k/100)^(−E)`
- Модель не знает про конкурентов, скидки и реакцию постоянных клиентов: шагайте по 5–7% и проверяйте на живом месяце

## Публикация

1. Создайте репозиторий (например, `pricing`).
2. Загрузите в корень `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ссылка на основной сайт настраивается в начале файла:

```html
<script>window.SITE_URL = '../';</script>
```

Для отдельного репозитория: `window.SITE_URL = 'https://username.github.io/site/';`

## Правки

Исходники — в `src/` (`template.html`, `extra.css`, `app.js`). Общая типографика и шапка — в `../assets/tools/base.css`. Пересборка:

```bash
python3 build.py
```
