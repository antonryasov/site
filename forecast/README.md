# Прогноз спроса

Отдельная страница-инструмент: 12 месяцев истории, четыре метода прогноза, проверка точности (MAPE), сезонные индексы и страховой запас. Всё в одном файле `index.html` — стили, шрифты, логика. Без внешних зависимостей.

## Что внутри

| Блок | Что делает |
|---|---|
| Живая карточка в шапке | Прогноз на следующий месяц, сумма за квартал, пик сезона, страховой запас и оценка ошибки |
| История | 12 полей: продажи по месяцам в любых единицах — ночи, чеки, заказы, штуки |
| Методы | Наивный, скользящее среднее (3 мес.), линейный тренд, тренд × сезонность |
| График | Столбцы истории и прогноза, коридор точности ±MAPE, линия «сегодня» |
| Метрики | Прогноз на месяц, сумма горизонта, страховой запас, MAPE, пик и дно сезона |
| Сравнение методов | Таблица: прогноз, ошибка, вердикт; лучший метод подсвечен |
| Контролы | Горизонт прогноза 1–12 мес. и срок поставки 0,5–6 мес. |
| Пресеты | Отель, кофейня, интернет-магазин, B2B-услуги |

Состояние сохраняется в адресе (`#h=120-118-150…&m=season&f=6&lt=1.5`) — ссылку можно отправить клиенту.

## Формулы

- Тренд — МНК по индексам месяцев: `y = a + b·i`
- Сезонный индекс — отношение факта к тренду, сглаженное по соседним месяцам и нормированное к среднему 1
- Сезонный прогноз = `(a + b·i) · индекс месяца`
- MAPE = среднее |факт − прогноз| / факт × 100% (наивный, среднее и тренд — на последних 3 месяцах, сезонная модель — по остаткам года)
- Страховой запас = `1,65 · σ остатков · √(срок поставки)`

## Публикация

1. Создайте репозиторий (например, `forecast`).
2. Загрузите в корень `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ссылка на основной сайт настраивается в начале файла:

```html
<script>window.SITE_URL = '../';</script>
```

Для отдельного репозитория: `window.SITE_URL = 'https://username.github.io/site/';`

## Правки

Исходники — в `src/` (`template.html`, `extra.css`, `app.js`). Общая типографика и шапка — в `../assets/tools/base.css`. Пересборка:

```bash
python3 build.py
```
