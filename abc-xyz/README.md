# ABC/XYZ-анализ ассортимента

Отдельная страница-инструмент: ABC по доле выручки, XYZ по коэффициенту вариации и матрица 3×3 с решением для каждой клетки. Всё в одном файле `index.html` — стили, шрифты, логика. Без внешних зависимостей.

## Что внутри

| Блок | Что делает |
|---|---|
| Живая карточка в шапке | Сколько позиций в группе A, их доля в выручке, размер «зоны риска» и доля C |
| Список позиций | Редактируемая таблица: название, выручка за период, разброс спроса в процентах. Добавление и удаление строк |
| Мини-полоски | У каждой строки — доля выручки и текущий класс (`AX`, `BY`, `CZ`…) |
| Матрица 3 × 3 | По горизонтали ABC, по вертикали XYZ: число позиций, доля выручки и текст решения |
| Таблица | Полный список по убыванию выручки: доля, накопленная доля, классы и короткое решение |
| Пресеты | Винный магазин, отель (бар и услуги), кофейня, B2B-склад |

Состояние сохраняется в адресе (`#d=Название~выручка~разброс;…`) — ссылку можно отправить клиенту.

## Правила

- **ABC:** позиции сортируются по выручке, считается накопленная доля: до 80% — A, до 95% — B, остальное — C.
- **XYZ:** коэффициент вариации до 10% — X, 10–25% — Y, больше 25% — Z.
- **Клетки:** AX — держать в норме, AZ — под заказ или предоплата, CZ — выводить и так далее: у всех девяти клеток есть решение.
- **Ловушка:** ABC по выручке не равно ABC по прибыли. Позиция может давать выручку и не давать маржу.

## Публикация

1. Создайте репозиторий (например, `abc-xyz`).
2. Загрузите в корень `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ссылка на основной сайт настраивается в начале файла:

```html
<script>window.SITE_URL = '../';</script>
```

Для отдельного репозитория: `window.SITE_URL = 'https://username.github.io/site/';`

## Правки

Исходники — в `src/` (`template.html`, `extra.css`, `app.js`). Общая типографика и шапка — в `../assets/tools/base.css`. Пересборка:

```bash
python3 build.py
```
