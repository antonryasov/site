# Симулятор архетипов бренда

Отдельная страница-инструмент: 12 архетипов бренда, тест из 10 вопросов, разборы с примерами, сравнение архетипов и «примерка» — как бренд звучит на сайте, в соцсетях и в ответе на негативный отзыв.

Всё в одном файле `index.html`: стили, шрифты (base64), тексты и логика. Внешних зависимостей нет — работает офлайн, на GitHub Pages и в любом статичном хостинге.

## Что внутри страницы

| Блок | Что делает |
|---|---|
| Колесо архетипов | 12 символов по кругу: наведение показывает название, клик открывает разбор |
| Симулятор | 10 вопросов, прогресс, возврат назад, клавиши 1–4, результат с распределением |
| Результат | Главный архетип, второй по силе, сильные стороны, риски, бренды, примерка текстов, копирование результата |
| Библиотека | Все 12 архетипов карточками, фильтр по 4 мотивациям, сравнение двух архетипов |
| Разбор архетипа | Обещание, тон голоса, слоганы, визуальные коды, кому подходит, риски, пример в гостеприимстве |
| Метод | Зачем архетип бизнесу и чего он не делает (без обещаний чудес) |

## Публикация отдельным репозиторием

1. Создайте репозиторий, например `brand-archetypes`.
2. Загрузите в корень три файла: `index.html`, `README.md`, `.nojekyll`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Через пару минут страница откроется по адресу `https://username.github.io/brand-archetypes/`.

## Как связать с основным сайтом

В `index.html` в самом начале есть одна строка:

```html
<script>
  window.SITE_URL = '../';
</script>
```

От неё зависят все ссылки «на основной сайт», «Обсудить бренд» и ссылки в подвале.

- Если инструмент лежит **внутри основного сайта** (папка `archetypes/` рядом с `index.html`) — оставьте `'../'`.
- Если это **отдельный репозиторий** — поставьте полный адрес основного сайта, например:
  `window.SITE_URL = 'https://username.github.io/site/';`

Обратная ссылка: на основном сайте блок «Симулятор архетипов бренда» стоит на странице `#/insights`, плюс ссылка в подвале. Она ведёт на `archetypes/index.html` — если инструмент живёт отдельно, замените этот адрес на полный.

## Как править контент

Исходники лежат в `src/`:

| Файл | Что содержит |
|---|---|
| `src/data.js` | 12 архетипов (тексты, примеры, тон, риски, «примерка») и 10 вопросов с весами |
| `src/style.css` | Вся вёрстка и адаптив |
| `src/app.js` | Логика: тест, подсчёт, галерея, разборы, сравнение, маршруты |
| `src/template.html` | Каркас страницы |

После правок:

```bash
python3 build.py      # соберёт index.html со вшитыми шрифтами
```

Скрипт берёт шрифты из `../assets/fonts` (Playfair Display и DM Sans), ужимает их и вставляет в файл. Если папки со шрифтами нет — страница соберётся с системной антиквой, работать будет.

### Как считается результат

Каждый вариант ответа даёт 2–3 очка нескольким архетипам. Чтобы архетипы, которые реже встречаются в вопросах, не проигрывали из-за структуры теста, итоговый балл делится на «базовую частоту» архетипа (сколько очков он получает при случайном ответе). Победитель — максимум по нормированному баллу; проценты в результате считаются относительно главного архетипа.

## Возможности для пользователя

- **Клавиши:** `1`–`4` — ответить, `←` — назад, `Esc` — закрыть разбор, `←` `→` — листать архетипы в разборе.
- **Ссылки на состояние:** `#/sim` — тест, `#/a/sage` — разбор конкретного архетипа, `#/compare/sage-jester` — сравнение, `#/result` — последний результат.
- **Результат сохраняется** в `localStorage`, кнопка «Скопировать результат» кладёт в буфер текст с архетипом, вторым по силе и подписью.
- **Без аналитики и трекеров** по умолчанию. Если нужна Яндекс.Метрика — вставьте её код в `<head>` шаблона перед сборкой.

## Доступность и техника

- Один файл ≈ 215 КБ, шрифты внутри, без сетевых запросов.
- Адаптив от 360 px: колесо, карточки и таблица сравнения перестраиваются.
- `prefers-reduced-motion` отключает анимации, у кнопок и карточек есть `:focus-visible`.
- Тёмная панель результата, светлые разборы, хеш-маршруты без перезагрузки.
